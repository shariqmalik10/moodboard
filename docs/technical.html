How Moodboard works

What it is for, how it runs your code, how Claude Code talks to it, and how to build it yourself.

Why it exists

Interfaces get tuned by eye. A radius, a duration or a font size is right when it looks right next to everything else, and that is hard to judge one component at a time in a browser tab.

Moodboard puts every component of a project on one wall, running, so you can compare them side by side. When something is off, you move a dial while you watch it, and the dial writes the new value into your source. The tuned version and the built version are the same file, so nothing has to be copied back by hand.

How it runs your project

  • The app is native Swift. Each live tile is a web view, and at most 12 run at once. The rest show stills.
  • Connecting a project starts a Vite server on your Mac. It runs each exported client component on its own, inside every *Provider your layout.tsx files wrap around the page, with your Tailwind and fonts.
  • Props a component needs are made up from its TypeScript types, so it has something to show. These sample props never touch your files.
  • Every other dial is a literal in your code: a Tailwind class, an inline style or a value in a stylesheet. Moving it rewrites that one literal, and the project’s own hot reload redraws the tile, usually in under 200 ms.
  • A component that throws or draws nothing stays off the wall, and the app says why.

Connect a project

Drag the project’s folder onto the wall, choose File > Connect Next.js Project…, or ask Claude Code to connect it. The folder can be the app, a folder inside it, or a monorepo. A monorepo with several apps asks which one. The project needs its packages installed and Node 20.19 or newer.

Claude Code

Moodboard is also an MCP server. The welcome sheet can add it, or run this once:

claude mcp add -s user moodboard -- ~/Applications/Moodboard.app/Contents/MacOS/Moodboard --mcp

Then, in Claude Code, ask it to “connect this project to moodboard”, or ask for “the component open on my wall”. If the wall is closed, the first call opens it.

Tools

connect_project
Connects a project, by default the folder Claude Code is in, and reports what joined.
list_projects, disconnect_project
Show or remove connected projects. Files stay as they are.
list_components, status
What is on the wall, what is open, and what is tuned, noted or built.
get_component
A component’s brief: your note, the tuned values, and the code with the tune applied.
open_component, set_dials
Open a component and set its dials. On a project component this writes the file.
set_note, mark_built
Leave a note, or record that the code now matches the tune.
import_from_paper
Brings a frame from the Paper design app onto the wall to tune before it is code.

Prompts

connect, implement_component, build_tuned, apply_notes and design_in_paper. In Claude Code, type /mcp__moodboard__ to see them.

Build from source

Needs Xcode and Node 20.19 or newer, and works on Intel Macs too.

git clone https://github.com/shariqmalik10/moodboard.git
cd moodboard && scripts/build.sh

Run npm run typecheck and npm test to check the web parts. The README has the code map, the Xcode tests and the known limits.
