Privacy

Moodboard has no account, no analytics and no telemetry. Your code stays on your Mac.

What stays on your Mac

  • Your project runs on a Vite server on your Mac, reachable only from it.
  • Tunes, notes, pictures, stills and the server cache live in ~/Library/Application Support/Moodboard. Nothing is written into your project except the literals you change with a dial.
  • Paper is read through its local server on your Mac. Moodboard never writes to Paper.

What can reach the internet

  • Your components load what they would load in a browser, such as Google fonts. Images and fonts in Paper designs load from Paper.
  • Send runs Claude Code on your Mac with the component’s brief. Claude Code sends it to Anthropic under your own Claude Code account, as any Claude Code request does. Nothing is sent until you press Send or ask Claude Code yourself.
  • The install command and the zip download come from GitHub.

This website

This site is hosted on GitHub Pages. It sets no cookies and runs no analytics. GitHub may keep its own server logs.

Remove everything

Delete the app and ~/Library/Application Support/Moodboard. If you added it to Claude Code, run claude mcp remove moodboard -s user.
