Your components, on a wall, running.

A Mac app for people who build interfaces. Connect a Next.js project and every component plays on an endless wall. Move a dial and it rewrites your source.

Install View the source Free and open source. Runs on your Mac and sends nothing anywhere.

Move a dial. The code moves with it.

Every dial is a literal in your file, such as a Tailwind class or an inline style. Drag one and Moodboard rewrites that literal while you drag. Edit the file and the tile redraws. Try both here.

Drag a dial, or click a highlighted number in the code and type. In the app this is your real file, and the tile is your real component.

Open a tile and it's yours.

Each tile plays its component in a loop, with a cursor pressing the real buttons. Click one and the loop stops where it stands. Hover it, type in it, tune it.

Works with what you already use.

Next.js

Point it at a project folder. Client components run in isolation, inside your layout's providers, with your Tailwind and fonts. Save a file and its tile redraws in about 200 ms.

Paper

Import frames from the Paper design app. Tune them on the wall before they're code, and see when the design changes.

Claude Code

Claude Code can see the wall, open components and set dials. Write a note on a tuned component and send it to be built into your project.

Install

Moodboard needs macOS 26 or later. To connect projects, it also needs Node 20.19 or newer.

One command

Downloads the latest release into ~/Applications and opens it. For Apple silicon.

curl -fsSL https://raw.githubusercontent.com/shariqmalik10/moodboard/main/scripts/install.sh | sh

Download the app

Moodboard.zip from the latest release. The app isn't notarized, so the first time you open it, macOS stops it. Open System Settings, then Privacy & Security, and click Open Anyway.

Build from source

Needs Xcode and Node. Works on Intel Macs too.

git clone https://github.com/shariqmalik10/moodboard.git && cd moodboard && scripts/build.sh
