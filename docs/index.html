Move a dial. The code moves with it.

Every dial is a literal in your file, such as a Tailwind class or an inline style. Drag one and Moodboard rewrites that literal while you drag. Edit the file and the tile redraws. Try both here.

Works with what you already use.

Next.js

Point it at a project folder. Client components run in isolation, inside your layout's providers, with your Tailwind and fonts. Save a file and its tile redraws in about 200 ms.

Paper

Import frames from the Paper design app. Tune them on the wall before they're code, and see when the design changes.

Claude Code

Claude Code can see the wall, open components and set dials. Write a note on a tuned component and send it to be built into your project.

Install

Moodboard needs macOS 26 or later. To connect projects, it also needs Node 20.19 or newer. The first launch checks for Node, offers a small demo project to play with, and can add Moodboard to Claude Code.

One command

Downloads the latest release into ~/Applications and opens it. For Apple silicon.

curl -fsSL https://raw.githubusercontent.com/shariqmalik10/moodboard/main/scripts/install.sh | sh

Download the app

Moodboard.zip from the latest release. The app isn't notarized, so the first time you open it, macOS stops it. Open System Settings, then Privacy & Security, and click Open Anyway.

Build from source

Needs Xcode and Node. Works on Intel Macs too.

git clone https://github.com/shariqmalik10/moodboard.git && cd moodboard && scripts/build.sh

Questions

Does my code leave my Mac?
No. Moodboard has no account and sends nothing anywhere. It runs your project with a small server on your Mac, and keeps that server's cache outside the project.
What does a dial write?
One literal in your file, and only while you move the dial. Opening the panel writes nothing. If the file changes in your editor while you tune, your editor wins.
Which components show up?
Each exported client component in the project, running on its own inside the providers your layouts wrap around the page. One that throws or draws nothing stays off the wall, and the app says why.
Do I need Claude Code or Paper?
No. Both are optional. Without them, Moodboard is a wall for your Next.js components, and the demo project needs nothing at all.
Why does macOS stop it the first time?
The app isn't notarized. The install command doesn't hit this, because curl doesn't mark the file as downloaded. For a copy from a browser, click Open Anyway in Privacy & Security.
How do I remove it?
Delete the app and ~/Library/Application Support/Moodboard. If you added it to Claude Code, run claude mcp remove moodboard -s user.
